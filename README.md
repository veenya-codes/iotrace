# ⚡ IoTrace

**IoTrace** is an industrial-grade, web-based visual circuit diagram builder designed for IoT hardware documentation, rapid prototyping, and clean technical schematics. Wrapped in a glassmorphic, retro-futuristic interface, it replaces messy hobbyist wiring with crisp, 90-degree orthogonal routing.

## ✨ Key Features
* **Infinite Blueprint Canvas:** Smooth panning and zooming on a scalable dark-mode grid.
* **Orthogonal Rubber-Banding Traces:** Wires automatically route at clean 90-degree angles and dynamically adjust when components are moved.
* **Informative Hardware Footprints:** Pre-loaded with accurate pinout layouts for popular IoT boards and sensors.
* **Dual-Theme Export:** Switch between the glowing **Terminal Mode** and a high-contrast **Print Mode** before exporting your diagram as a `.png` image.
* **Custom Annotations:** Place editable text notes directly onto the schematic canvas.

## 📦 Included Hardware Library
* **Microcontrollers:** STM32 Nucleo, STM32 Blue Pill, AT89S52 (8051), Wemos D1 Mini (ESP8266)
* **Displays & Modules:** 16x2 LCD, 7-Segment Display, USB-to-TTL (FTDI), BME280 Sensor
* **Prototyping & Discrete:** Standard Breadboard, Pushbuttons, Multi-color LEDs

## 🛠️ Tech Stack
* HTML5 / CSS3 (Tailwind CSS)
* Vanilla JavaScript & SVG Coordinate Matrix
* Hosted on Vercel
